# AlgoMarket Decision Lab ⚡

An interactive microeconomic simulation platform evaluating tacit algorithmic collusion, econometric price-discrimination auditing, and regulatory welfare design.

## Features
- **Collusion Risk Lab**: Multi-agent reinforcement learning simulation with Q-learning pricing bots.
- **Price Discrimination Auditor**: Statistical group tests and multi-variable OLS regression to audit pricing bias.
- **Regulatory Design Lab**: Dual-linked simulations connecting government policy to firm behavior and consumer welfare.
- **Policy Comparison & Calibration**: Welfare cost-benefit analysis and empirical elasticity presets.
